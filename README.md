# INFRA website — infraworld.org

Marketing and product site for **INFRA**, an EVM-compatible Layer 1 that launches 1:1 currency-pegged stablecoin networks (reAED for the UAE Dirham is live).

Built with **Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS 4 · GSAP + Lenis** (motion) and plain Canvas 2D for the animated graphics. Deployed on **Vercel** (region `dub1`).

---

## Quick start

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production build (also type-checks)
npm run lint     # ESLint
```

Node 20+ recommended.

## How things work

- **Motion** — Only pages that render `<Effects />` (home, reAED, wallet) get smooth scroll, GSAP reveals and the custom cursor. Elements with class `rv` fade/slide in on scroll; `.sc` labels "scramble" in. Users with *Reduce motion* enabled get a static site.
- **Canvases** — `lib/canvas.ts` exports renderers that take a `<canvas>` and return a cleanup function. They pause when off-screen, resize via `ResizeObserver`, cap pixel ratio on phones, and re-read the theme every frame.
- **Theme** — `<html data-theme="light|dark">`. A tiny script in `app/layout.tsx` restores the saved choice before paint (no flash). Light is the default.
- **First paint** — on `/` and `/reaed`, the `<html class="intro">` class hides hero elements until GSAP starts the intro (removed in `Effects.tsx`; 2.5s safety timeout).
- **Build form emails** — submitted from the browser to [FormSubmit](https://formsubmit.co) → `BUILD_FORM_EMAIL`. The very first submission sends a one-time activation email to that inbox.
- **Pool balances** — `/api/infra/balances` reads `recipients(0..5)` (vault + bps) from the DistributionPool contract, then each vault's balance; Validators uses `ValidatorStaking.rewardReserve()`. Falls back to `config/pools.ts`. The page polls it every 30s.
- **SEO** — root metadata in `app/layout.tsx`, per-page `metadata` exports, JSON-LD via `components/common/JsonLd.tsx` + `lib/seo.ts`, plus generated sitemap/robots/OG image.

## Conventions

- One component per file, named export, file name = component name.
- Page-specific sections live under `components/sections/<page>/`; anything reused goes in `components/common` or `sections/shared`.
- Editable values go in `src/config/`, copy-heavy content in `src/content/`.
- Styles: plain CSS classes in `src/styles/` (Tailwind is available but the design system uses its own classes). Use the CSS variables from `tokens.css` — never hard-code colours, so dark mode keeps working.
- Every file starts with a one-line comment saying what it is; functions have a short `/** … */` doc comment.
