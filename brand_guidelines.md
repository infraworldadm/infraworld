## INFRA Website — Brand Guidelines

### 1) Color Palette

- **Strong black**: `#000000`
- **Light grey**: `#F1F4F2`
- **White**: `#FFFFFF`
- **Dark gradient**: `#000000 → #3D3D3D` (vertical)
- **Light gradient**: `#EEEEEE → #F0F3F1` (vertical)
- **Blue for CTA**: `#006BFF`

---

### 2) Typeface

- **Font family**: IBM Plex Sans

---

### 3) Font Weights

- **Regular**
- **Medium**
- **SemiBold**
- **Bold**

Specimen strings:
- `ABCDEFGHIJKLMNOPQRSTUVWXYZ`
- `abcdefghijklmnopqrstuvwxyz`
- `0123456789`
- `!@#$%^&*()_+-=[]{}|;:'",.<>/?`

---

### 4) Type Scaling

- **H1**: 64px
- **H2**: 48px
- **H3**: 36px
- **H4 / Body**: 24px

---

### 5) Overall Design Language

- Minimalist
- Black / white / grey base with one accent color (CTA blue)
- High contrast
- Modern / technical / SaaS / infrastructure-style branding
- Clean grid layout
- Sans-serif typography only
